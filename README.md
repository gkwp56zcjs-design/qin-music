# 中国儿歌数字博物馆

一个面向儿童、家长和教师的互动数字博物馆，也是数字教材《钢琴弹唱教程》的拓展空间。

## 当前内容

- 中国地域儿歌馆藏与故事导览
- 可操控的“小童”角色
- “你唱一句、馆长接一句”互动
- 世界经典儿歌展厅
- 参观者作品墙与留言板
- PDF、MP3、MOV、MP4、PNG、JPG 资源入口
- 留言和投稿数据结构

## 在线演示

https://china-nursery-rhyme-museum.c9qczrhq49.chatgpt.site/

部分网络环境可能拦截该域名，因此仓库中同时提供完整源码压缩包。

## 使用源码

下载仓库根目录中的 `china-nursery-rhyme-museum-source.zip`，解压后阅读其中的 `DEPLOYMENT-GUIDE.md`。

需要 Node.js 22 或更高版本。

```bash
npm install
npm run dev
```
